# AI Systems Inbox

面向 AI 系统工程的只读论文简报站。手机与电脑使用浏览器访问，不需要安装本地后端。

## 当前阶段

正在初始化静态阅读页面及 GitHub Pages 发布流程。仓库创建和网页发布不需要模型 API。

完整的无人值守中文简报生成仍需接通并验收模型执行通道；目前不启用付费模型、不上传订阅登录凭据，也不把原文摘要冒充完整中文分析。

## 内容与隐私

公开仓库只允许网站代码和经过确认可公开的论文简报。

- 不上传历史会话 ZIP、个人数据库、笔记、反馈或聊天摘录。
- 不上传 `.env`、API Key、访问令牌、`auth.json` 或浏览器登录数据。
- 访客只有阅读权限；站内收藏、笔记和登录不属于这一阶段的范围。
- 历史论文必须先核对标题、编号、版本及来源，不默认将旧聊天中的分析视为已验证事实。

## 目标流程

官方 arXiv 批次 → 完整性检查 → 去重与分析 → 保存公开简报 → 发布静态网页。

批次处理进度与网页发布结果必须分开记录。网络错误、生成错误和发布错误不能被显示为“没有新论文”。
